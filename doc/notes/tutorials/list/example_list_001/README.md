# 🎓 Οδηγός Εγκατάστασης & Εκτέλεσης Python για Πρωτοετείς Φοιτητές ΕΜΠ

## Εργαστήριο: Χειρισμός Λιστών (`example_list_001.py`)

Καλώς ήρθατε στο πρώτο σας εργαστήριο Προγραμματισμού στο ΕΜΠ! Σε αυτόν τον
οδηγό θα μάθετε:

1. Πώς να **δημιουργήσετε από το μηδέν** το περιβάλλον εργασίας σας με το
   `micromamba` και το `uv`.
2. Πώς να **ενεργοποιήσετε** το περιβάλλον.
3. Πώς να **εκτελέσετε** το πρόγραμμα διαχείρισης λίστας
   [`src/tutorial/list/example_list_001/example_list_001.py`](file:///C:/usr/src/ntua/chemeng/sandbox-python-pclab/src/tutorial/list/example_list_001/example_list_001.py)
   μέσω της γραμμής εντολών (**Windows Terminal / PowerShell 7**).

---

## 🛠️ Μέρος Α: Αρχική Ρύθμιση & Δημιουργία Περιβάλλοντος (Εκτελείται Μόνο 1 Φορά)

### Βήμα 0.1: Δημιουργία του Περιβάλλοντος Micromamba από το `environment.yml`

Το αρχείο
[`environment.yml`](file:///C:/usr/src/ntua/chemeng/sandbox-python-pclab/environment.yml)
περιέχει τις οδηγίες για την εγκατάσταση της βασικής έκδοσης της Python (3.14)
και του εργαλείου διαχείρισης πακέτων `uv`.

Ανοίξτε το **Windows Terminal** (PowerShell 7) στο φάκελο του project και
εκτελέστε:

```powershell
micromamba env create -f environment.yml -y
```

---

### Βήμα 0.2: Ενεργοποίηση του Βασικού Περιβάλλοντος Micromamba

Μόλις ολοκληρωθεί η εγκατάσταση, ενεργοποιήστε το περιβάλλον πληκτρολογώντας:

```powershell
micromamba activate python-mastery-sandbox
```

---

### Βήμα 0.3: Δημιουργία του Εσωτερικού Περιβάλλοντος UV (`.venv`) & Παραγωγή του `uv.lock`

Το αρχείο
[`pyproject.toml`](file:///C:/usr/src/ntua/chemeng/sandbox-python-pclab/pyproject.toml)
περιγράφει όλες τις πρόσθετες βιβλιοθήκες που χρειάζεται το εργαστήριο.

Εκτελέστε την παρακάτω εντολή. Το `uv` θα διαβάσει το `pyproject.toml`, θα
δημιουργήσει τον τοπικό φάκελο απομόνωσης **`.venv/`** και θα παραγάγει αυτόματα
το αρχείο **`uv.lock`** (το οποίο «κλειδώνει» τις ακριβείς εκδόσεις των
βιβλιοθηκών ώστε να λειτουργούν πάντα σωστά):

```powershell
uv sync --python python
```

---

## 🚀 Μέρος Β: Καθημερινή Εκτέλεση του Προγράμματος

Κάθε φορά που ανοίγετε ένα νέο τερματικό για να δουλέψετε, ακολουθείτε τα
παρακάτω απλά βήματα:

### Βήμα 1: Ενεργοποίηση του Περιβάλλοντος Micromamba

```powershell
micromamba activate python-mastery-sandbox
```

---

### Βήμα 2: Προετοιμασία Δικαιωμάτων Εκτέλεσης στα Windows (Μόνο αν χρειαστεί)

Τα Windows προστατεύουν το σύστημα απαγορεύοντας την εκτέλεση scripts. Δώστε
προσωρινή άδεια στο παράθυρο του τερματικού σας εκτελώντας:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned -Force
```

---

### Βήμα 3: Ενεργοποίηση του Εσωτερικού Εικονικού Περιβάλλοντος (`.venv`)

Ενεργοποιήστε το εσωτερικό περιβάλλον του project:

```powershell
.\.venv\Scripts\Activate.ps1
```

> [!NOTE] Μόλις εκτελεστεί επιτυχώς, θα δείτε στην αρχή της γραμμής εντολών την
> ένδειξη **`(.venv)`**. Αυτό επιβεβαιώνει ότι βρίσκεστε μέσα στο σωστό
> περιβάλλον!

---

### Βήμα 4: Εκτέλεση του Προγράμματος με Αρχικά Δεδομένα και Προσθήκη Στοιχείου (`--add`)

Θα εκτελέσουμε το αρχείο `example_list_001.py` δίνοντάς του:

- **Αρχικά στοιχεία λίστας** με το διακόπτη `--data` (π.χ. `apple` και `banana`)
- **Ένα νέο στοιχείο για προσθήκη** στο τέλος της λίστας με το διακόπτη `--add`
  (π.χ. `cherry`)

Εκτελέστε:

```powershell
python src/tutorial/list/example_list_001/example_list_001.py --data apple banana --add cherry
```

---

### 🖥️ Αναμενόμενο Αποτέλεσμα στην Οθόνη σας

Μόλις πατήσετε **Enter**, το πρόγραμμα θα εμφανίσει τη νέα ενημερωμένη λίστα:

```text
Result: ['apple', 'banana', 'cherry']
```

---

### 💡 Εναλλακτικός Σύγχρονος Τρόπος (Σε 1 Μόνο Εντολή με το `uv`)

Στη σύγχρονη Python, μπορείτε να παραλείψετε τα Βήματα 2 & 3 και να εκτελέσετε
το πρόγραμμα απευθείας με το εργαλείο `uv run`:

```powershell
uv run src/tutorial/list/example_list_001/example_list_001.py --data apple banana --add cherry
```
